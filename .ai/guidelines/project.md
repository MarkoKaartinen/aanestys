# Project

## Language

- Write all code in English: class, method and variable names, comments, commit messages and PR descriptions.
- The application's primary language is English, with Finnish as a supported translation. Put user-facing strings in translation files, never hardcode them.

## Principles

- Follow KISS and YAGNI. Do not build features, abstractions, config options or dependencies "just in case".
- Prefer Laravel's own solutions (Eloquent, HTTP client, policies, notifications, scheduler, queues).
- Money is stored as integers (cents), never floats.
